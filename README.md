# Tom-Riddle-s-Diary
📜 复刻《哈利·波特》汤姆·里德尔的魔法日记本网页，斯莱特林复古风格，可登录注册，支持普通日记模式 / AI汤姆里德尔对话模式切换。
📖项目介绍
本项目复刻哈利波特世界观中汤姆·里德尔的日记本。
网页整体采用斯莱特林复古绿色主题。用户可以注册账号、设置密码登录系统；登录后打开虚拟日记本。日记本页面为羊皮纸复古UI。
提供两种使用模式：
1. AI开启模式：输入日记内容，AI以汤姆·里德尔的人设给出个性化对话反馈，模拟和日记本灵魂对话。
2. AI关闭模式：纯粹本地日记本，仅保存用户书写的笔记，无AI回复。
项目完整包含前端页面、后端服务、数据库三部分。
✨功能清单
用户账号模块
• 用户注册：设置用户名 + 密码，账号存入数据库
• 用户登录：用户名密码校验，身份鉴权
• 会话保存：登录状态维持，退出登录功能
UI界面
1. 首页封面：斯莱特林主题，复古绿色调，笔记本封面样式，带有斯莱特林徽章元素。
2. 登录/注册弹窗页面。并选择AI的语言（中文或英文）
3. 日记本主体页面：羊皮纸纹理背景，复古字体，仿真日记本视觉效果。AI的回复会用花体字呈现出缓慢展现状。
日记本核心功能
• 日记本文本编辑，书写日记内容
• 模式切换开关：开启AI / 关闭AI
◦ ✅AI开启：提交文本，后端调用大模型API，返回汤姆·里德尔人设的回复，回复展示在日记本内
◦ ❌AI关闭：仅保存用户书写内容，无AI对话反馈
• 日记持久化存储：用户所有日记内容保存数据库，登录后可以读取历史日记记录
• 历史日记查阅，查看过往书写记录
🛠技术栈
• 前端：HTML + CSS + JavaScript
样式：复古羊皮纸、斯莱特林绿色主题，适配浏览器
• 后端：Node.js + Express
处理登录注册接口、日记读写接口、对接AI大模型API
• 数据库：SQLite（开发） / MySQL（生产）
数据表：用户表、日记数据表
• AI能力：调用第三方大模型API（DeepSeek / OpenAI等），Prompt固定汤姆·里德尔人设，生成对话回复
